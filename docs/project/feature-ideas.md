# Feature Ideas

Community-suggested features and enhancements.

See [Next Steps](next-steps.md) for planned roadmap.

## Proposed Features

### Input Enhancements
- Macro support (programmable key sequences)
- Mouse acceleration profiles
- Custom keymapping/remapping
- Gamepad/controller passthrough

### Connectivity
- USB-C direct connection mode
- WiFi-based HID (Android/iOS)
- Multiple simultaneous active hosts
- Daisy-chain multiple RPi units

### Display
- OLED display support
- RGB LED indicators
- E-paper display
- Virtual on-screen keyboard (for headless)

### Advanced Features
- Screen recording/screenshot
- OCR from captured video
- Automated testing (simulated input)
- Wake-on-LAN integration

## Suggestions Welcome

Open an issue or discussion to propose new features!
